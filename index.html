Introdução

Bem-vindo ao Desenvolvimento Web Back-end! Neste curso, você adquirirá as habilidades para criar aplicações web renderizadas no lado do servidor eficientes e escaláveis. Com base no seu conhecimento de front-end, você aprenderá a projetar e integrar bancos de dados relacionais, implementar estratégias robustas de validação e seguir frameworks e padrões de projeto modernos. Ao final do curso, você estará preparado para desenvolver aplicações dinâmicas e orientadas a dados que aderem às melhores práticas da indústria no desenvolvimento back-end.

Resultados de Aprendizagem do Curso (CLOs)

Ao longo deste curso, você desenvolverá as habilidades necessárias para criar uma aplicação web renderizada no lado do servidor que seja eficiente e escalável, enquanto continua a aplicar o conhecimento adquirido no desenvolvimento front-end. Ao final do semestre, você terá aprendido a:

  • Desenvolver aplicações web que sigam os padrões de front-end aprendidos anteriormente
  • Criar aplicações renderizadas no lado do servidor usando frameworks e padrões de projeto modernos
  • Projetar e integrar bancos de dados relacionais para operações CRUD
  • Implementar estratégias apropriadas de validação no lado do cliente e do servidor
  • Articular a terminologia, os princípios e as melhores práticas do desenvolvimento web back-end

Uso de IA

De acordo com a política de IAdo Departamento de Ciência da Computação, a IA deve ser usada com responsabilidade como uma ferramenta para apoiar seu aprendizado, como um tutor ou mentor, em vez de concluir tarefas ou projetos para você. Se você usar a IA extensivamente ou não tiver certeza sobre seu uso, por favor, divulgue e credite-a em seu trabalho.

Ocasionalmente, você encontrará um destaque como este, evidenciando oportunidades para aproveitar a IA para aprimorar sua experiência de aprendizado. A maioria dos destaques é opcional, mas alguns podem exigir que você use a IA para uma tarefa específica e relate suas descobertas. Se for solicitado que você compartilhe um chat de IA, use uma ferramenta como o ChatGPT que permita compartilhar o histórico do chat, e garanta que você mantenha o chat até que seu instrutor o tenha analisado.

Sem Armazenamento na Nuvem

Armazene todo o seu trabalho em seu repositório do GitHub. Não use serviços de armazenamento na nuvem, como Google Drive, Dropbox ou OneDrive, para os arquivos do curso. O GitHub mantém seu trabalho salvo em backup, versionado e acessível ao seu instrutor e colegas.

Nunca coloque seu repositório Git local dentro de uma pasta sincronizada com a nuvem. Os serviços em nuvem podem modificar arquivos, bloqueá-los ou criar arquivos temporários que corrompem seu repositório e causam erros difíceis de corrigir. Evite dores de cabeça futuras mantendo seu repositório Git em uma pasta local padrão e usando o GitHub para backup e colaboração.
