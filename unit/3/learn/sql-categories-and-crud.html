Categorias da Linguagem SQL e Operações CRUD

Na sua leitura anterior, você aprendeu sobre os fundamentos de banco de dados relacional. Agora, exploraremos como interagir com bancos de dados PostgreSQL por meio de diferentes tipos de comandos SQL, com foco especial na compreensão da relação entre as categorias da linguagem SQL e as operações CRUD.

Entendendo as Categorias de Comandos SQL

Os comandos SQL (Structured Query Language) no PostgreSQL podem ser categorizados com base em sua finalidade e no nível em que atuam. Essa categorização ajuda a entender a distinção entre os comandos que modificam a estrutura do banco de dados e aqueles que manipulam os próprios dados.

Linguagem de Definição de Dados (DDL)

Os comandos DDL operam no nível da estrutura do banco de dados e são usados para definir, modificar ou remover objetos do banco de dados, como tabelas, índices e esquemas. Quando você executa comandos DDL, está alterando como seu banco de dados está organizado, em vez de manipular os registros de dados reais.

Os comandos DDL comuns no PostgreSQL incluem:

  • CREATE – Cria novos objetos do banco de dados, como tabelas ou índices
  • ALTER – Modifica a estrutura de objetos de banco de dados existentes
  • DROP – Remove permanentemente objetos do banco de dados
  • TRUNCATE – Remove rapidamente todos os dados de uma tabela enquanto preserva sua estrutura

Linguagem de Manipulação de Dados (DML)

Os comandos DML operam no nível de dados e permitem gerenciar os registros reais armazenados nas tabelas do seu banco de dados. Esses comandos não alteram a estrutura do seu banco de dados, apenas as informações contidas nele.

Os principais comandos DML no PostgreSQL são:

  • INSERT – Adiciona novos registros a uma tabela
  • UPDATE – Modifica registros existentes
  • DELETE – Remove registros de uma tabela
  • SELECT – Recupera dados de uma ou mais tabelas (às vezes categorizada separadamente como DQL - Linguagem de Consulta de Dados)

Linguagem de Controle de Dados (DCL)

Os comandos DCL se concentram no controle de acesso aos dados dentro do banco de dados. Eles gerenciam permissões e privilégios de usuário, definindo quem pode acessar quais dados e quais operações podem executar.

Os principais comandos DCL no PostgreSQL incluem:

  • GRANT – Concede privilégios específicos aos usuários
  • REVOKE – Remove privilégios concedidos anteriormente

Linguagem de Controle de Transação (TCL)

Os comandos TCL gerenciam transações dentro do banco de dados, permitindo controlar quando as alterações são aplicadas permanentemente ou revertidas.

Os comandos TCL importantes no PostgreSQL incluem:

  • BEGIN – Inicia uma transação
  • COMMIT – Salva permanentemente todas as alterações feitas durante a transação atual
  • ROLLBACK – Desfaz todas as alterações feitas durante a transação atual
  • SAVEPOINT – Define um ponto dentro de uma transação para o qual você pode reverter posteriormente

Operações CRUD e Comandos SQL

CRUD significa Create, Read, Update e Delete (Criar, Ler, Atualizar e Excluir) – as quatro operações fundamentais que você realiza nos dados em qualquer sistema de banco de dados. Compreender o CRUD é essencial porque essas operações formam a espinha dorsal de quase todas as interações com bancos de dados em aplicações web.

Cada operação CRUD corresponde diretamente a comandos SQL específicos: 


        | CRUD Operation | SQL Command | Description                                    |
        |----------------|-------------|------------------------------------------------|
        | Create         | INSERT      | Adds new records to a table                    |
        | Read           | SELECT      | Retrieves data from the database               |
        | Update         | UPDATE      | Modifies existing records in a table           |
        | Delete         | DELETE      | Removes records from a table                   |
Por que o CRUD Importa

As operações CRUD representam as formas fundamentais pelas quais os usuários interagem com os dados em qualquer aplicação. Quer alguém esteja criando uma conta, visualizando seu perfil, atualizando suas informações ou excluindo uma publicação, essa pessoa está realizando operações CRUD que se traduzem diretamente em comandos SQL.

Operações em Nível de Banco de Dados vs. Nível de Dados

Um conceito crítico para entender é a distinção entre operações que funcionam no nível da estrutura do banco de dados versus aquelas que operam nos próprios dados. Essa distinção ajuda a esclarecer a relação entre as categorias da linguagem SQL e os níveis nos quais elas operam.

Operações em Nível de Banco de Dados: Afetam a estrutura, esquema ou organização do seu banco de dados (tabelas, colunas, restrições, etc.). Esses são principalmente comandos DDL.

Operações em Nível de Dados: Afetam as informações reais armazenadas nas estruturas do seu banco de dados. Esses são principalmente comandos DML e correspondem às operações CRUD.

Visualizando a Relação

A tabela a seguir ilustra como as categorias da linguagem SQL se mapeiam para os níveis de operação: 


        | Operation Level | SQL Category | Example Commands                                |
        |-----------------|--------------|-------------------------------------------------|
        | Database Level  | DDL          | CREATE TABLE, ALTER TABLE, DROP TABLE, TRUNCATE |
        | Database Level  | DCL          | GRANT, REVOKE                                   |
        | Data Level      | DML          | INSERT, UPDATE, DELETE                          |
        | Data Level      | DQL          | SELECT                                          |
        | Data Level      | TCL          | COMMIT, ROLLBACK, SAVEPOINT                     |

Comparações Principais

Entender as diferenças entre comandos com nomes semelhantes que operam em níveis diferentes é crucial para escolher a ferramenta certa para cada tarefa: 


        | Data Level | Database Level | Key Difference                                         |
        |------------|----------------|--------------------------------------------------------|
        | DELETE     | DROP           | DELETE removes records; DROP removes entire table      |
        | DELETE     | TRUNCATE       | Both remove data, but TRUNCATE resets table completely |
        | UPDATE     | ALTER          | UPDATE changes data values; ALTER changes structure    |

Exemplos no Contexto

Vamos explorar como esses conceitos funcionam juntos em um cenário prático. Imagine que você está trabalhando com um banco de dados simples de livraria online, onde você precisa tanto configurar a estrutura quanto gerenciar os dados.

Nota de Aprendizado

Estamos usando comandos SQL completos para demonstrar claramente as diferenças entre as categorias de comandos. Em ambientes de desenvolvimento reais, você pode usar uma sintaxe mais curta, ferramentas de linha de comando ou interfaces gráficas, mas entender a sintaxe completa ajuda a compreender o que está realmente acontecendo.

Operações em Nível de Banco de Dados (Estrutura)

Primeiro, você definiria a estrutura do seu banco de dados usando comandos DDL: 


        -- Creating a new table (DDL - Database Level)
        CREATE TABLE books (
            book_id SERIAL PRIMARY KEY,
            title VARCHAR(100) NOT NULL,
            author VARCHAR(100) NOT NULL,
            price DECIMAL(10,2),
            category VARCHAR(50),
            publication_date DATE
        );

        -- Modifying table structure by adding a column (DDL - Database Level)
        ALTER TABLE books ADD COLUMN in_stock BOOLEAN DEFAULT true;

        -- Setting up access permissions (DCL - Database Level)
        GRANT SELECT ON books TO store_staff;
        GRANT INSERT, UPDATE, DELETE ON books TO store_managers;

Operações em Nível de Dados (Conteúdo)

Após definir a estrutura, você usaria comandos DML para manipular os dados reais, implementando todas as quatro operações CRUD: 


        -- Adding a new book record (DML - Data Level - CREATE)
        INSERT INTO books (title, author, price, category, publication_date) 
        VALUES ('Database Fundamentals', 'Jane Smith', 29.99, 'Technology', '2023-05-15');

        -- Retrieving book information (DQL - Data Level - READ)
        SELECT title, author, price FROM books WHERE category = 'Technology';

        -- Updating a book's price (DML - Data Level - UPDATE)
        UPDATE books SET price = 24.99 WHERE title = 'Database Fundamentals';

        -- Removing a book record (DML - Data Level - DELETE)
        DELETE FROM books WHERE title = 'Database Fundamentals';

        -- Managing a transaction for multiple operations (TCL - Data Level)
        BEGIN;
        INSERT INTO books (title, author, price, category, publication_date) 
        VALUES ('SQL Essentials', 'John Doe', 34.99, 'Technology', '2024-01-10');
        UPDATE books SET price = price * 0.9 WHERE category = 'Technology';
        COMMIT;

Considerações de Desempenho e Segurança

Entender as categorias de comandos também ajuda a tomar melhores decisões sobre desempenho e segurança dos dados:

Quando Usar Cada Tipo de Comando

Situações diferentes exigem abordagens diferentes:

  • Use DELETE quando você precisa remover registros específicos com base em condições
  • Use TRUNCATE quando você precisa remover todos os registros rapidamente e redefinir contadores de auto-incremento
  • Use DROP quando você precisa remover completamente uma tabela e sua estrutura
  • Use transações (BEGIN/COMMIT/ROLLBACK) ao executar várias operações relacionadas que devem ter sucesso ou falhar juntas
Nota Importante de Segurança

Operações em nível de banco de dados (DDL) geralmente não podem ser revertidas em transações da mesma forma que operações em nível de dados podem. No PostgreSQL, muitas operações DDL fazem commit imediatamente e não podem ser incluídas em um bloco de transação para reversão. Sempre verifique novamente os comandos DDL antes de executá-los em ambientes de produção.

Resumo dos Conceitos Principais

Entender as categorias da linguagem SQL e sua relação com os níveis de operação é fundamental para trabalhar de forma eficaz com o PostgreSQL. Você aprendeu que as operações em nível de banco de dados (principalmente DDL e DCL) definem e gerenciam a estrutura e os controles de acesso do seu banco de dados, enquanto as operações em nível de dados (principalmente DML, DQL e TCL) manipulam e recuperam as informações reais armazenadas nessas estruturas.

As operações CRUD (Create, Read, Update, Delete) se mapeiam diretamente para os comandos DML do SQL e representam as principais interações de dados que você executará em aplicações web. Entender as diferenças entre comandos semelhantes que operam em níveis diferentes ajuda a escolher a abordagem certa para cada tarefa do banco de dados e a evitar erros dispendiosos.
