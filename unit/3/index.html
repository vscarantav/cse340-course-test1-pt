Visão Geral da Unidade 3

Nesta unidade, fazemos a transição do desenvolvimento front-end para sistemas completos de back-end ao introduzirmos a integração de banco de dados, autenticação de usuário e gerenciamento de sessão em nosso sistema de informações universitárias. Você aprenderá como os bancos de dados organizam informações, dominará conceitos essenciais de SQL e implementará operações CRUD para interação dinâmica com dados.

Além disso, você criará sistemas de autenticação com contas de usuário, páginas protegidas e funcionalidades baseadas em sessão, como mensagens flash para feedback do usuário. Ao final desta unidade, seu site estático se tornará uma aplicação segura, dinâmica e orientada a dados, com gerenciamento de usuários e armazenamento persistente de dados via PostgreSQL.

Fique Atento aos Dados do Modelo

Nesta Unidade, faremos a transição de dados JSON diretamente no código para um banco de dados PostgreSQL. A estrutura dos dados evoluirá ao longo do tempo, portanto, preste muita atenção ao formato de cada Tarefa. O banco de dados armazena dados em snake_case (ex.: first_name), mas seus modelos devem continuar retornando dados para os controladores em camelCase (ex.: firstName). Isso significa que você precisará converter entre formatos nas suas funções de modelo. Mesmo que o código inicial funcione corretamente, é sua responsabilidade garantir que ele retorne os dados no formato adequado.

Parte A: Dados Relacionais e PostgreSQL

Bancos de dados relacionais, fundamentos de SQL e CRUD, PostgreSQL com pgAdmin, passagem por valor vs. referência e organização enquanto você deixa de usar dados em código fixo.

Conclua o seguinte na ordem especificada até as datas de vencimento listadas no Canvas ou antes do final da unidade se nenhuma data estiver listada:

  • Introdução aos Bancos de Dados Relacionais
    Descubra como os bancos de dados relacionais organizam, armazenam e gerenciam grandes quantidades de dados de maneira eficiente, garantindo a integridade e a acessibilidade dos dados para aplicações modernas.
  • Configuração do pgAdmin
    Configure o pgAdmin, uma poderosa interface gráfica para gerenciar bancos de dados PostgreSQL, para se conectar ao seu banco de dados e praticar operações básicas de banco de dados.
  • Fundamentos do SQL
    Aprenda os conceitos fundamentais e a sintaxe do SQL, capacitando você a escrever consultas com confiança para recuperar, filtrar e manipular dados em bancos de dados relacionais.
  • Categorias da Linguagem SQL e Operações CRUD
    Explore as categorias essenciais de comandos SQL e domine as operações fundamentais—Criar, Ler, Atualizar e Deletar (CRUD)—para gerenciar e manter efetivamente o conteúdo do seu banco de dados.
  • Introdução ao PostgreSQL
    Configure seu banco de dados PostgreSQL e aprenda como se conectar a ele usando o pgAdmin, permitindo gerenciar e interagir com seus dados de maneira eficaz.
  • Passagem por Valor vs. Passagem por Referência
    Entenda as diferenças entre passar dados por valor e por referência na programação, e como esses conceitos impactam o gerenciamento de memória e a manipulação de dados em suas aplicações.
  • Refatoração de Organização
    Refatore sua aplicação Express para melhorar a organização, o desempenho e a legibilidade ao consolidar middleware, implementar o carregamento dinâmico de recursos e reorganizar exibições.
  • Desafio de Código: Transição de Emergência
    Finalize o site quase completo de um colega de trabalho após uma emergência médica familiar, concluindo as tarefas pendentes restantes e lapidando os detalhes finais para o lançamento.

Parte B: Formulários, Sessões e Contas Seguras

Métodos HTTP, sessões e armazenamento, consultas preparadas, validação, hashing vs. criptografia e fluxos de registro/login.

Conclua o seguinte na ordem especificada até as datas de vencimento listadas no Canvas ou antes do final da unidade se nenhuma data estiver listada:

  • Métodos HTTP
    Aprenda as diferenças entre os métodos HTTP GET e POST, seus papéis em aplicações web e como usá-los no Express. Explore brevemente outros métodos HTTP, como PUT, DELETE e PATCH, e entenda como cada um permite diferentes tipos de interações cliente-servidor.
  • Sessões e Armazenamento de Sessão
    Entenda como funcionam as sessões de aplicações web, o papel do armazenamento de sessão na manutenção do estado do usuário e como implementar sessões em suas aplicações Express para aprimorar a experiência do usuário e a segurança.
  • Criando Seu Primeiro Formulário
    Construa um formulário de contato funcional para vivenciar a validação no lado do cliente e do servidor, o armazenamento seguro de dados no PostgreSQL e o feedback do usuário por meio da visualização de mensagens no aplicativo após o envio.
  • Consultas Preparadas
    Aprenda sobre consultas preparadas em SQL, seus benefícios para a segurança e o desempenho, e como implementá-las em suas interações com o banco de dados para se proteger contra ataques de injeção de SQL.
  • Validação de Dados no Cliente e no Servidor
    Aprenda sobre a validação da entrada do usuário tanto no lado do cliente quanto do servidor para garantir a integridade dos dados, aprimorar a segurança e melhorar a experiência do usuário em aplicações web.
  • Hashing vs. Criptografia
    Entenda as diferenças fundamentais entre hashing e criptografia, seus respectivos casos de uso e como aplicar cada método adequadamente para proteger dados confidenciais em suas aplicações.
  • Criando um Formulário de Registro
    Construa um sistema de registro de usuários com hashing de senhas, validação abrangente e gerenciamento de usuários usando Express, PostgreSQL e bcrypt.
  • Criando um Formulário de Login
    Construa uma página de login segura e um painel protegido usando sessões do Express e PostgreSQL. Implemente autenticação, gerenciamento de sessões e proteção de rotas para contas de usuário.
