Desafio de Programação: Funcionalidades do Corpo Docente

Nesta tarefa de desafio, você aplicará seus conhecimentos de Express, EJS e arquitetura MVC para melhorar o tratamento de erros e criar um novo sistema de diretório do corpo docente. Esta tarefa se baseia nos conceitos de parâmetros de rota e na estrutura MVC que você aprendeu em tarefas anteriores.

O desafio consiste em duas tarefas principais que ajudarão você a praticar:

  • Criar um sistema de diretório do corpo docente usando os mesmos padrões de parâmetro de rota que você aprendeu com o catálogo de cursos
  • Aprimorar o diretório do corpo docente com ordenação por parâmetros de consulta
Faça Commit de Suas Alterações

Você já deve ter o hábito de fazer commit de suas alterações regularmente. Se ainda não fez isso, certifique-se de fazer o commit do seu trabalho antes de iniciar esta tarefa. Isso ajudará você a acompanhar seu progresso e reverter alterações, se necessário.

Gerenciamento de Branchs do Git

Para esta tarefa, você aprenderá a usar branches do Git para manter seu trabalho experimental separado da sua base de código principal. Criar uma branch permite que você trabalhe em novas funcionalidades sem afetar sua branch principal em funcionamento, e você pode facilmente alternar de volta se algo der errado.

Crie uma nova branch para o trabalho desta tarefa: 


        # Create and switch to a new branch for this assignment
        git checkout -b faculty-directory

Você pode verificar se está na branch correta usando: 


        git branch
        
        # or for more details
        
        git status

Trabalhe na tarefa nesta branch. Se precisar alternar de volta para sua branch principal por qualquer motivo, use: 


        git checkout main

E para alternar de volta para a branch da sua tarefa: 


        git checkout faculty-directory

Após concluir todas as tarefas nesta tarefa, você pode mesclar suas alterações de volta para a sua branch principal: 


        # First commit your changes in the faculty-directory branch
        git add .
        git commit -m "Complete faculty directory system"
        
        # Switch to main branch
        git checkout main
        
        # Merge changes from faculty-directory branch
        git merge faculty-directory
        
        # Push to remote repository
        git push
        
        # Optionally delete the feature branch
        git branch -d faculty-directory

Instruções do Desafio

1. Construir um Sistema de Diretório do Corpo Docente

Você criará um novo sistema de diretório do corpo docente que usa os mesmos padrões de parâmetro de rota que aprendeu com o catálogo de cursos. Este será um sistema completamente separado que pratica os mesmos conceitos técnicos com conteúdos diferentes, evitando que você simplesmente copie e cole o código do seu catálogo de cursos.

O diretório do corpo docente incluirá uma lista de todos os membros do corpo docente e páginas de perfil individuais de professores, usando rotas como /faculty e /faculty/:facultyId.

Corrigiremos isso em breve, mas a partir de agora, todo código novo, como a nova página do corpo docente, seguirá o padrão MVC correto.

Construir os Controladores do Corpo Docente

Crie src/controllers/faculty/faculty.js com manipuladores de rota para as páginas de lista e detalhes do corpo docente. Siga o mesmo padrão utilizado nos controladores de curso:

  • Importe as funções do modelo do corpo docente
  • Crie uma facultyListPage função que renderiza a página de lista do corpo docente
  • Crie uma facultyDetailPage função que usa parâmetros de rota para procurar membros individuais do corpo docente
  • Inclua o tratamento de erros adequado para IDs de corpo docente inválidos
  • Exporte ambas as funções

Criar Rotas do Corpo Docente

Atualize seu src/routes.js arquivo para incluir as rotas do corpo docente:

  • Importe seus controladores do corpo docente
  • Adicione uma /faculty rota para a lista do corpo docente
  • Adicione uma /faculty/:facultyId rota para detalhes individuais do corpo docente

Construa as Views do Corpo Docente (Incluindo Estilos)

Arquivos Iniciais Disponíveis

Para ajudar você a focar na lógica de back-end, fornecemos arquivos de modelo iniciais e estilos CSS. Tente construir tudo sozinho primeiro para maximizar seu aprendizado, mas se você ficar preso na apresentação do front-end, você pode baixar estes arquivos como ponto de partida. Você pode fazer engenharia reversa dos modelos EJS para entender a estrutura de dados que seus controladores precisam fornecer.

Crie os modelos do corpo docente seguindo a mesma estrutura dos seus modelos do catálogo de cursos:

Modelo de Lista do Corpo Docente (src/views/faculty/list.ejs):

  • Exiba todos os membros do corpo docente em um formato de grade ou lista
  • Faça com que o nome de cada membro do corpo docente seja um link para sua página de detalhes
  • Mostre informações básicas como nome, departamento e cargo
  • Inclua navegação adequada de volta ao site principal

Modelo de Detalhes do Corpo Docente (src/views/faculty/detail.ejs):

  • Exiba informações detalhadas sobre o membro do corpo docente
  • Inclua nome, sala, telefone, e-mail, departamento e cargo
  • Forneça um link de volta para a lista do corpo docente
  • Siga os mesmos padrões de estilização das suas páginas de detalhes do curso

Atualizar Navegação

Testando Sua Implementação

Teste seu diretório do corpo docente visitando estas URLs:

  • http://127.0.0.1:3000/faculty - Deve mostrar a lista de todo o corpo docente
  • http://127.0.0.1:3000/faculty/brother-jack - Deve mostrar os detalhes do Irmão Jack
  • http://127.0.0.1:3000/faculty/sister-anderson - Deve mostrar os detalhes da Irmã Anderson
  • http://127.0.0.1:3000/faculty/invalid-person - Deve mostrar a página de erro 404 e não a sua página de erro 500

Testando a Ordenação do Corpo Docente

Teste sua funcionalidade de ordenação com estas URLs:

  • http://127.0.0.1:3000/faculty - Ordenação padrão por nome
  • http://127.0.0.1:3000/faculty?sort=department - Ordenado por departamento
  • http://127.0.0.1:3000/faculty?sort=title - Ordenado por cargo
  • http://127.0.0.1:3000/faculty?sort=name - Ordenado por nome
  • http://127.0.0.1:3000/faculty?sort=invalid - Não deve mostrar um erro, mas sim usar como padrão a ordenação por nome
Reconhecimento de Padrões

Observe como você está aplicando os mesmos padrões de parâmetros de consulta que aprendeu com a ordenação de seções de cursos. Essa repetição ajuda a consolidar seu entendimento sobre como o Express lida com diferentes tipos de parâmetros de URL.

Construindo sobre o Que Você Já Sabe

Este diretório do corpo docente usa exatamente os mesmos padrões técnicos que você aprendeu com o catálogo de cursos: parâmetros de rota, busca de objetos, renderização de modelos e tratamento de erros. A única diferença é a estrutura de dados e o conteúdo. Se você entende como o sistema de cursos funciona, pode aplicar os mesmos conceitos aqui.

Dicas e Sugestões

Aqui estão algumas dicas adicionais para ajudar você a concluir a Tarefa:

  • Diretório de Corpo Docente (Tarefa 1):
    • Olhe para os seus controladores de curso e modelos existentes como exemplos
    • O padrão de busca de corpo docente é idêntico à busca de curso: faculty[facultyId]
    • Teste cada parte incrementalmente: funções de modelo primeiro, depois controladores e, em seguida, modelos
    • Não se esqueça de tratar o caso em que alguém faz a requisição de um ID de corpo docente inválido
  • Ordenação do Corpo Docente (Tarefa 2):
    • Revise como você implementou a ordenação de seções do curso para obter orientação
    • Lembre-se de converter o objeto do corpo docente em um array antes de ordenar
    • Use os do JavaScript Object.values() e sort() métodos

Se você encontrar problemas, adote uma abordagem sistemática:

  1. Verifique o console do seu servidor para mensagens de erro e rastreamentos de pilha
  2. Verifique se os caminhos dos arquivos e as instruções de importação estão corretos
  3. Teste uma rota por vez antes de passar para a próxima
  4. Compare a sua implementação de corpo docente com a sua implementação de curso funcional

Resumo dos Conceitos-Chave

Esta Tarefa de desafio reforçou os conceitos fundamentais do Express e do MVC por meio da repetição prática. Você praticou parâmetros de rota, padrões de busca de objetos, renderização de modelos, manipulação de parâmetros de consulta e gerenciamento de erros usando um domínio completamente diferente do seu catálogo de cursos.

O sistema de diretório de corpo docente demonstra como os mesmos padrões técnicos podem ser aplicados a diferentes tipos de dados e casos de uso. Entender esses padrões transferíveis é essencial para construir aplicações web maiores e mais complexas.

Ao implementar o tratamento de erros específico para cada ambiente, você também aprendeu considerações importantes sobre a implantação em produção que os desenvolvedores profissionais devem abordar ao construir aplicações do mundo real.
