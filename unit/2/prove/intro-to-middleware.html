Entendendo e Usando Middleware no Express

Nesta tarefa, você implementará os conceitos de middleware que aprendeu na atividade de leitura. As funções de middleware permitem processar requisições, compartilhar dados em toda a sua aplicação e criar funcionalidades reutilizáveis que tornam seu código mais limpo e organizado. Ao final desta tarefa, você obterá uma compreensão sólida de como criar funções de middleware, usar res.locals para compartilhar dados entre views e aplicar middleware tanto globalmente quanto a rotas específicas.

Preparação

Antes de iniciar a tarefa, vamos criar uma seção em seu arquivo server.js especificamente para funções de middleware. Isso ajudará a manter seu código organizado à medida que você adiciona várias funções de middleware ao longo da tarefa. Logo antes dos seus manipuladores de rota, adicione o seguinte: 


        /**
         * Configure Express middleware
         */

        // Middleware to make NODE_ENV available to all templates
        app.use((req, res, next) => {
            res.locals.NODE_ENV = NODE_ENV.toLowerCase() || 'production';

            // Continue to the next middleware or route handler
            next();
        });

Este middleware define a NODE_ENV variável em res.locals, tornando-a acessível em todos os seus modelos EJS. Isso é útil para renderizar conteúdo condicionalmente com base no ambiente (desenvolvimento ou produção). Normalmente você combinaria várias funções de middleware juntas, mas para fins de clareza, estamos adicionando-as uma de cada vez nesta tarefa.

Instruções da Tarefa

1. Introdução ao Middleware

Comece adicionando uma função de middleware simples para registrar em log as requisições recebidas no console. Isso ajudará você a entender como o middleware processa cada requisição que chega ao seu servidor.

Adicione o seguinte middleware ao seu arquivo server.js na sua seção de middleware existente: 


        app.use((req, res, next) => {
            // Skip logging for routes that start with /. (like /.well-known/)
            if (!req.path.startsWith('/.')) {
                console.log(`${req.method} ${req.url}`);
            }
            next(); // Pass control to the next middleware or route
        });

Salve seu arquivo e navegue para diferentes páginas em sua aplicação. Observe seu console para ver os logs de cada requisição. Isso demonstra como o middleware é executado para cada requisição antes de atingir seus manipuladores de rota. Após confirmar que funciona, você pode remover a linha console.log.

2. Usando res.locals para Dados Globais

O objeto res.locals permite definir dados que estarão disponíveis para todos os seus modelos automaticamente. Isso elimina a necessidade de passar os mesmos dados para cada rota.

Adicione este middleware à sua seção de funções de middleware: 


        // Middleware to add global data to all templates
        app.use((req, res, next) => {
            // Add current year for copyright
            res.locals.currentYear = new Date().getFullYear();
            
            next();
        });

Agora atualize seu parcial footer.ejs para usar o ano dinâmico: 


        <footer>
            <p>&copy; <%= currentYear %> My Express App.</p>
        </footer>

Salve ambos os arquivos e atualize qualquer página. Seu rodapé agora deve mostrar o ano atual automaticamente, sem que você precise passá-lo a partir de cada rota.

4. Adicionar Middleware de Randomização de Tema

Crie um middleware que selecione aleatoriamente um tema de cores para cada carregamento de página. Isso demonstra como o middleware pode afetar a aparência visual do seu site.

Sua tarefa: Conclua este middleware para atribuir aleatoriamente um dos três temas. 


        // Global middleware for random theme selection
        app.use((req, res, next) => {
            const themes = ['blue-theme', 'green-theme', 'red-theme'];
            
            // Your task: Pick a random theme from the array

            res.locals.bodyClass = randomTheme;
            
            next();
        });

Atualize seu header.ejs para usar o tema aleatório:

Adicione este CSS ao seu conjunto de regras body existente no main.css arquivo para ver os temas em ação:

Se você não estiver familiarizado com este conceito, reserve um momento para revisá-lo com um colega de equipe ou solicitando esclarecimentos à IA.

5. Criar Middleware Auxiliar de Parâmetro de Consulta

Crie um middleware que torne os parâmetros de consulta facilmente acessíveis para todos os seus modelos. Implemente o middleware e comprove que está funcionando imprimindo os dados na página do curso (por exemplo, views/course-details.ejs).

Sua tarefa: Conclua este middleware para disponibilizar os parâmetros de consulta globalmente e, em seguida, atualize o modelo de detalhes do curso para exibi-los para verificação. 


        // Global middleware to share query parameters with templates
        app.use((req, res, next) => {
            // Make req.query available to all templates for debugging and conditional rendering
            res.locals.queryParams = req.query || {};
            
            next();
        });

Teste: Acesse uma URL de detalhes do curso com parâmetros de consulta (por exemplo, /catalog/[course]?sort=professor) e confirme se os parâmetros aparecem na página.

Dica: Exibindo o Status de Ordenação

Esta tarefa foi projetada para que você pratique o uso de middleware para compartilhar dados em sua aplicação, além de editar modelos EJS. Desenvolver familiaridade com a renderização condicional no EJS é uma habilidade importante para construir aplicações web dinâmicas.

Entendendo o Middleware Global vs. Específico de Rota

Através desta Tarefa, você experimentou ambos os tipos de middleware:

Dois Tipos de Middleware

Middleware global (usando app.use()) é executado para cada requisição para sua aplicação. Seus middlewares de saudação, tema e parâmetro de consulta são globais.

Middleware específico de rota só é executado para rotas específicas onde você o inclui. O middleware da sua página de demonstração só é executado quando alguém acessa /demo.

Resumo dos Conceitos-Chave

Você implementou com sucesso um middleware que demonstra padrões essenciais do Express: processar dados de requisições, compartilhar informações na sua aplicação e aplicar funcionalidades seletivamente. Sua página de demonstração mostra como todas essas peças funcionam juntas para criar uma experiência de aplicação coesa.

Os conceitos de middleware que você praticou são fundamentais para construir aplicações web profissionais: compartilhamento global de dados, geração dinâmica de conteúdo, processamento de requisições e aplicação seletiva de funcionalidades.
