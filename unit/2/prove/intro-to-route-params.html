Construindo um Catálogo de Cursos com Parâmetros de Rota

Nesta Tarefa, você criará um sistema simples de catálogo de cursos que demonstra como os parâmetros de rota funcionam no Express. Você construirá duas páginas conectadas: uma lista de catálogo que mostra os cursos disponíveis e páginas de detalhes de cursos individuais que exibem informações específicas com base no ID do curso capturado da URL.

Esta prática mão na massa ajudará você a entender como os parâmetros de rota capturam valores dinâmicos de URLs e os usam para exibir conteúdos diferentes, desenvolvendo diretamente os conceitos que você aprendeu na atividade de leitura.

Configurando os Dados do Seu Curso

Como ainda não cobrimos bancos de dados ou fontes de dados externas, você trabalhará com um objeto JavaScript codificado diretamente que representa as informações do curso. Copie e cole esta estrutura de dados do curso em seu server.js arquivo, colocando-o perto do topo, após suas importações, mas antes de suas rotas:

Instruções da Tarefa

1. Crie a Página da Lista do Catálogo de Cursos

Comece criando uma rota que exiba todos os cursos disponíveis em uma lista simples. Adicione esta rota ao seu server.js arquivo antes do seu middleware de tratamento de erros: 


        // Course catalog list page
        app.get('/catalog', (req, res) => {
            res.render('catalog', {
                title: 'Course Catalog',
                courses: courses
            });
        });

Crie o modelo correspondente catalog.ejs em seu views diretório: 


        <%- include('partials/header') %>
        <main>
            <h1>Course Catalog</h1>
            <p>Browse our available courses and click on any course to see detailed information including available sections and instructors.</p>
            
            <div class="course-list">
                <% Object.values(courses).forEach(course => { %>
                    <div class="course-card">
                        <h3><a href="/catalog/<%= course.id %>"><%= course.title %></a></h3>
                        <p class="course-id"><%= course.id %> • <%= course.credits %> credits</p>
                        <p class="course-description"><%= course.description %></p>
                    </div>
                <% }); %>
            </div>
        </main>
        <%- include('partials/footer') %>

Adicione um link para o catálogo em sua navegação. Atualize seu header.ejs partial: 


        <nav>
            <ul>
                <li><a href="/">Home</a></li>
                <li><a href="/about">About</a></li>
                <li><a href="/catalog">Course Catalog</a></li>
                <li><a href="/products">Products</a></li>
            </ul>
        </nav>

Teste sua página de catálogo visitando http://127.0.0.1:3000/catalog. Você deve ver uma lista de três cursos, cada um com um link clicável.

2. Crie a Rota de Detalhes do Curso com Parâmetros

Agora implemente a rota que captura um ID de curso da URL e exibe informações detalhadas sobre esse curso específico. Adicione esta rota após a rota do seu catálogo: 


        // Course detail page with route parameter
        app.get('/catalog/:courseId', (req, res) => {
            // Extract the course ID from the URL
            const courseId = req.params.courseId;
            
            // Look up the course in our data
            const course = courses[courseId];
            
            // Handle course not found
            if (!course) {
                const err = new Error(`Course ${courseId} not found`);
                err.status = 404;
                return next(err);
            }
            
            // Log the parameter for debugging
            console.log('Viewing course:', courseId);
            
            // Render the course detail template
            res.render('course-detail', {
                title: `${course.id} - ${course.title}`,
                course: course
            });
        });

Crie o modelo de detalhes do curso course-detail.ejs em seu views diretório: 


        <%- include('partials/header') %>
        <main>
            <div class="course-header">
                <h1><%= course.title %></h1>
                <p class="course-meta"><%= course.id %> • <%= course.credits %> credits</p>
                <p class="course-description"><%= course.description %></p>
            </div>
            
            <div class="sections">
                <h2>Available Sections</h2>
                <div class="section-list">
                    <% course.sections.forEach(section => { %>
                        <div class="section-card">
                            <div class="section-time"><%= section.time %></div>
                            <div class="section-room">Room: <%= section.room %></div>
                            <div class="section-professor">Instructor: <%= section.professor %></div>
                        </div>
                    <% }); %>
                </div>
            </div>
            
            <div class="navigation">
                <p><a href="/catalog">&larr; Back to Course Catalog</a></p>
            </div>
        </main>
        <%- include('partials/footer') %>

Teste seu parâmetro de rota clicando em links de cursos da página do catálogo. Tente visitar URLs diretamente como /catalog/CS121, /catalog/MATH110, e /catalog/ENG101. Verifique o console do seu servidor para ver o ID do curso registrado.

Como os Parâmetros de Rota Funcionam

O :courseId no padrão da sua rota diz ao Express para capturar qualquer coisa que venha depois de /catalog/ e torná-la disponível como req.params.courseId. Quando alguém visita /catalog/CS121, o Express captura "CS121" e permite que você o use para procurar os dados específicos do curso.

3. Adicione Ordenação por Parâmetros de Consulta

Aprimore sua página de detalhes do curso adicionando a capacidade de ordenar seções usando parâmetros de consulta. Substitua sua rota de detalhes do curso pelo seguinte código: 


        // Enhanced course detail route with sorting
        app.get('/catalog/:courseId', (req, res, next) => {
            const courseId = req.params.courseId;
            const course = courses[courseId];
            
            if (!course) {
                const err = new Error(`Course ${courseId} not found`);
                err.status = 404;
                return next(err);
            }
            
            // Get sort parameter (default to 'time')
            const sortBy = req.query.sort || 'time';
            
            // Create a copy of sections to sort
            let sortedSections = [...course.sections];
            
            // Sort based on the parameter
            switch (sortBy) {
                case 'professor':
                    sortedSections.sort((a, b) => a.professor.localeCompare(b.professor));
                    break;
                case 'room':
                    sortedSections.sort((a, b) => a.room.localeCompare(b.room));
                    break;
                case 'time':
                default:
                    // Keep original time order as default
                    break;
            }
            
            console.log(`Viewing course: ${courseId}, sorted by: ${sortBy}`);
            
            res.render('course-detail', {
                title: `${course.id} - ${course.title}`,
                course: { ...course, sections: sortedSections },
                currentSort: sortBy
            });
        });

E substitua seu course-detail.ejs modelo por esta versão atualizada que inclui links de ordenação: 


        <%- include('partials/header') %>
        <main>
            <div class="course-header">
                <h1><%= course.title %></h1>
                <p class="course-meta"><%= course.id %> • <%= course.credits %> credits</p>
                <p class="course-description"><%= course.description %></p>
            </div>
            
            <div class="sections">
                <div class="sections-header">
                    <h2>Available Sections</h2>
                    <div class="sort-options">
                        <span>Sort by: </span>
                        <a href="/catalog/<%= course.id %>" class="<%= currentSort === 'time' ? 'active' : '' %>">Time</a>
                        <a href="/catalog/<%= course.id %>?sort=professor" class="<%= currentSort === 'professor' ? 'active' : '' %>">Professor</a>
                        <a href="/catalog/<%= course.id %>?sort=room" class="<%= currentSort === 'room' ? 'active' : '' %>">Room</a>
                    </div>
                </div>
                
                <div class="section-list">
                    <% course.sections.forEach(section => { %>
                        <div class="section-card">
                            <div class="section-time"><%= section.time %></div>
                            <div class="section-room">Room: <%= section.room %></div>
                            <div class="section-professor">Instructor: <%= section.professor %></div>
                        </div>
                    <% }); %>
                </div>
            </div>
            
            <div class="navigation">
                <p><a href="/catalog">&larr; Back to Course Catalog</a></p>
            </div>
        </main>
        <%- include('partials/footer') %>

Teste a funcionalidade de ordenação clicando nos links de ordenação em qualquer página de detalhes do curso. Tente URLs como:

  • /catalog/CS121?sort=professor
  • /catalog/MATH110?sort=room
  • /catalog/ENG101?sort=time
Para ajudar você a entender como os parâmetros de rota e de consulta funcionam juntos, adicionamos uma instrução de log no console que mostra tanto o ID do curso capturado quanto a opção de ordenação selecionada toda vez que você visita uma página de detalhes do curso. Sinta-se à vontade para removê-la assim que estiver confortável com a funcionalidade.

Resumo dos Conceitos-Chave

Você construiu com sucesso um sistema funcional de catálogo de cursos que demonstra os conceitos fundamentais de parâmetros de rota no Express. Sua aplicação captura IDs de cursos a partir da estrutura da URL, utiliza-os para buscar e exibir informações específicas do curso, e trata requisições inválidas de forma adequada por meio do seu sistema de erros existente.

A funcionalidade de ordenação mostra como parâmetros de rota e parâmetros de consulta funcionam juntos: o parâmetro de rota identifica qual curso exibir, enquanto o parâmetro de consulta modifica como as seções desse curso são apresentadas. Essa combinação cria URLs flexíveis e fáceis de usar que mantêm seu significado ao mesmo tempo em que fornecem opções de personalização.

Estes conceitos formam o fundamento para construir aplicações web dinâmicas que respondem à navegação do usuário enquanto mantêm estruturas de URL limpas e compreensíveis.

Experimente e Estenda

Pratique os conceitos de parâmetros de rota que você acabou de aprender com estas melhorias:

  1. Adicione Mais Cursos: Expanda o objeto courses com disciplinas adicionais como "HIST101" ou "BIOL150" e teste suas rotas com os novos dados.
  2. Crie uma Funcionalidade de Curso Aleatório: Adicione uma rota como /catalog/random que redireciona para uma página de detalhes do curso selecionado aleatoriamente.
  3. Validação Aprimorada: Adicione validação para garantir que os IDs dos cursos sigam o padrão esperado (letras seguidas por números) antes de buscá-los.

Estes experimentos foram projetados para aprofundar sua compreensão sobre como os parâmetros de rota se comportam em diferentes cenários, enquanto oferecem prática para desenvolver sobre os padrões que você acabou de implementar. Sua nota final depende de quão bem você aplica esses conceitos nos trabalhos do projeto do curso posteriormente, então dedique um tempo para explorar e fortalecer seu entendimento.
