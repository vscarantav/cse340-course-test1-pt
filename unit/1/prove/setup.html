Configurando seu ambiente de desenvolvimento

Introdução

Antes de começarmos a programar, é essencial configurar seu ambiente de desenvolvimento adequadamente. Este guia orientará você pelas etapas de instalação e configuração das ferramentas necessárias. Recomendamos os seguintes softwares:

  • VS Code (Visual Studio Code)
  • Node.js (v22+)
  • pnpm (v10+)

Observe que um Chromebook não é um dispositivo aceitável para este curso. Você precisará de um computador Windows, macOS ou Linux para concluir as Tarefas. Com Chromebooks mais recentes, você pode conseguir instalar um subsistema Linux, mas isso não é recomendado devido a potenciais problemas de compatibilidade e ao alto nível de conhecimento técnico necessário.

Instalando o VS Code

O VS Code é um editor de código leve, mas poderoso, que suporta JavaScript e muitas outras linguagens de programação. Seu instrutor usará este editor nas aulas e é o único que ele pode dar suporte prontamente. Siga estas etapas para instalar o VS Code:

  1. Acesse o site oficial: https://code.visualstudio.com/
  2. Baixe o instalador para o seu sistema operacional (Windows, macOS ou Linux).
  3. Execute o instalador e siga as instruções para concluir a instalação.

Uma vez instalado, você pode abrir o VS Code e explorar suas extensões para aprimorar sua experiência de programação.

Instalando ou atualizando o Node.js (v22+)

O Node.js é um ambiente de tempo de execução para executar código JavaScript fora do navegador. Se você estiver usando o Node Version Manager (NVM), use o NVM para instalar o Node.js. Instruções detalhadas específicas para cada sistema operacional sobre o NVM podem ser encontradas aqui. Se você preferir uma instalação direta ou tiver apenas uma versão do Node.js instalada, siga estas etapas:

  1. Visite o site oficial do Node.js: https://nodejs.org/
  2. Baixe a versão LTS (Suporte de Longo Prazo) mais recente para o seu sistema operacional.
  3. Execute o instalador e siga as instruções.
    • Windows: Use as opções padrão durante a instalação.
    • macOS: Arraste o aplicativo Node.js para a sua pasta Aplicações.
    • Linux: Siga as instruções específicas de instalação fornecidas no site.
  4. Verifique sua instalação abrindo um terminal e executando o seguinte comando. Lembre-se de que qualquer terminal aberto anteriormente não reconhecerá a nova instalação até que você o feche e abra novamente. Certifique-se de que a saída mostre um número de versão 20.11.0 ou superior: 
    
node --version

Instalando o pnpm (v10+)

O pnpm (Performant Node Package Manager) é um gerenciador de pacotes eficiente e rápido que recomendamos em vez do npm mais tradicional. Ao contrário do npm, o pnpm usa um sistema de armazenamento endereçável por conteúdo, o que significa que os pacotes são instalados apenas uma vez, mesmo que vários projetos dependam deles. Isso economiza espaço em disco e acelera seu fluxo de trabalho.

É altamente recomendado instalar o pnpm globalmente em seu sistema usando as instruções de instalação específicas do seu sistema operacional. Copiamos a maioria das instruções da página oficial de instalação do pnpm abaixo para sua conveniência:

Windows

Abra o PowerShell e execute o comando de instalação específico para Windows fornecido no site oficial: https://pnpm.io/installation

macOS

Instale o pnpm usando o Homebrew executando: 

brew install pnpm

Após a instalação, reinicie o terminal para garantir que as alterações surtam efeito. Em seguida, verifique a instalação executando: 

pnpm --version

Linux

Execute o seguinte comando para instalar o pnpm por meio de um script: 

curl -fsSL https://get.pnpm.io/install.sh | sh -

Certifique-se de que o pnpm foi adicionado ao seu PATH seguindo as instruções do script. Após a instalação, reinicie o seu terminal para garantir que as alterações tenham efeito. Em seguida, verifique a instalação executando: 

pnpm --version

Todos os Sistemas Operacionais Usando NPM

Esta opção não é recomendada, mas às vezes é necessária. Se você tem o Node.js instalado e prefere usar o npm, pode instalar o pnpm globalmente executando o seguinte comando no seu terminal:

  1. Certifique-se de que o Node.js está instalado; veja a seção anterior.
  2. Abra um terminal e execute o seguinte comando para instalar o pnpm globalmente: 
    
                    npm install -g pnpm
  3. Feche e abra novamente o seu terminal e, em seguida, verifique a instalação executando: 
    
                    pnpm --version
  4. Se as etapas acima falharem, tente instalar o pnpm usando as instruções específicas do sistema operacional.

Solução de problemas: PNPM não encontrado no PATH

Após instalar o PNPM, sempre feche e reabra o terminal para atualizar a PATH variável de ambiente do seu sistema. Se o PNPM ainda não for reconhecido, talvez seja necessário adicionar manualmente o local dele à sua PATH.

Para encontrar onde o PNPM foi instalado, baixe este script e execute: 

node find-pnpm-global-bin.mjs

O script exibirá na saída o diretório onde o binário do PNPM está localizado. Para usar o PNPM em qualquer janela do terminal, adicione este diretório à PATH variável de ambiente do seu sistema. Se você não tiver certeza de como fazer isso, pode pedir orientação a um assistente de IA, consultar as instruções para o seu sistema operacional ou entrar em contato com o seu instrutor ou monitor para obter ajuda.

Conclusão

Configurar o seu ambiente de desenvolvimento com as ferramentas necessárias é o primeiro e mais importante passo neste curso. Concluir esta configuração com antecedência ajudará você a trabalhar de forma mais eficiente. Se você encontrar algum problema durante a instalação, sinta-se à vontade para entrar em contato com seus colegas, ajudar uns aos outros ou consultar recursos online e a documentação oficial. Você também pode buscar orientação com o monitor do curso, se disponível, ou com o instrutor. Trabalhar juntos e utilizar esses recursos ajudará você a superar quaisquer desafios e se manter no caminho certo neste semestre.

Assim que tiver concluído a configuração, você estará pronto para começar a realizar as tarefas desta unidade. Você precisará de software adicional para tarefas futuras, mas esta configuração será suficiente para as primeiras semanas. O instrutor fornecerá instruções para qualquer software adicional necessário à medida que o curso avançar.
