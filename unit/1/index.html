Visão Geral da Unidade 1

Nesta unidade, vamos configurar seu ambiente de desenvolvimento, mergulhar em conceitos-chave de desenvolvimento web e dar o pontapé inicial na sua primeira aplicação Express. As unidades geralmente duram duas semanas no curso semestral (14 semanas) e uma semana no curso de bloco (7 semanas). Para se manter no caminho certo, é crucial concluir as atividades na ordem apresentada e dentro do prazo. As tarefas "prove" são as mais importantes. Se você tiver alguma dúvida ou precisar de ajuda, não hesite em entrar em contato com sua equipe, assistente de ensino (se disponível), tutor (se disponível) ou instrutor.

Parte A: Ambiente de Desenvolvimento e Habilidades Web Essenciais

Configuração de ferramentas, nivelamento em JavaScript (funções arrow, promises, módulos ESM), CSS aninhado moderno, caminhos de arquivo e URL, frameworks vs. bibliotecas e sua primeira aplicação Express com fluxo de trabalho do GitHub.

Conclua o seguinte na ordem especificada até as datas de entrega listadas no Canvas ou antes do final da unidade se nenhuma data estiver listada:

  • Configuração do Ambiente
    Este guia orienta você na configuração do seu ambiente de desenvolvimento com ferramentas essenciais como Visual Studio Code, Node.js, pnpm e DB Browser para SQLite, garantindo que você esteja pronto para o curso.
  • História do JavaScript
    Explore as origens, a evolução e os principais avanços do JavaScript. Este recurso oferece nivelamento para os alunos preencherem lacunas em sua compreensão, enquanto também serve como uma introdução para iniciantes e uma reciclagem para aqueles com conhecimento prévio.
    • Funções Arrow
      Aprenda sobre funções arrow, uma maneira concisa de escrever funções em JavaScript. Este recurso cobre a sintaxe, funcionalidades e boas práticas para usar funções arrow em seu código. Espera-se que você escreva e use funções arrow em suas tarefas.
    • Promises
      Mergulhe nas promises, uma funcionalidade poderosa no JavaScript para lidar com operações assíncronas. Este recurso explica como as promises funcionam, como criá-las e consumi-las, e como lidar com erros. O framework Express usa promises extensivamente, então compreendê-las é crucial para construir aplicações web.
    • Módulos
      Compare CommonJS e ES Modules, e aprenda a criar e usar seus próprios módulos em JavaScript. Este recurso fornece um fundamento sólido para organizar e reutilizar código em seus projetos. Espera-se que você escreva código ESM em suas tarefas.
  • CSS Aninhado Moderno
    Descubra as técnicas mais recentes no CSS moderno, incluindo regras aninhadas, propriedades personalizadas e seletores avançados. Essas funcionalidades permitem que você escreva folhas de estilo mais limpas e fáceis de manter, enquanto aproveita todo o poder do CSS para designs responsivos e dinâmicos.
  • Entendendo Caminhos de Arquivo e URL
    Aprenda a diferença entre caminhos absolutos, relativos e relativos à raiz em sistemas de arquivos e no desenvolvimento web.
Nivelamento de Habilidades

As atividades de aprendizagem acima revisaram conceitos de JavaScript com os quais você já deve estar familiarizado de cursos anteriores e introduziram tópicos de CSS que serão úteis ao longo deste curso. Se algo parecer desconhecido, não espere. Use ferramentas de tutoria com IA, recursos online ou entre em contato com sua equipe, assistente de ensino, tutor ou instrutor. Quanto antes você sanar as lacunas, mais fácil será acompanhar o curso.

  • Frameworks vs. Bibliotecas
    Aprenda os papéis distintos de frameworks e bibliotecas no desenvolvimento web. Frameworks fornecem uma abordagem estruturada para construir aplicações, enquanto bibliotecas oferecem código reutilizável para tarefas específicas. Dominar ambos é essencial para um desenvolvimento eficaz.
  • Repositório do GitHub
    Este guia ajuda você a configurar e gerenciar um repositório Git para o seu projeto, cobrindo a instalação e a configuração do Git, a criação de um repositório local, a adição de um arquivo .gitignore e o envio do seu projeto para o GitHub. Ele também fornece etapas para verificar seus benefícios de estudante do GitHub Pro e oferece recursos para aprendizado adicional.
  • Seu Primeiro Aplicativo Express
    Nesta Tarefa, você configurará um projeto Node.js usando pnpm, adicionará o Express para um servidor web e usará o Nodemon para reinicializações automáticas. Você trabalhará com variáveis de ambiente e criará rotas para praticar a construção do seu primeiro aplicativo web renderizado no lado do servidor.

Parte B: Roteamento, Middleware e Visualizações no Lado do Servidor

Ciclo de vida de requisição–resposta, arquitetura de 3 camadas, roteamento e arquivos estáticos do Express, criação de modelos EJS e recarregamento ao vivo.

Conclua o seguinte na ordem especificada até as datas de vencimento listadas no Canvas ou antes do final da unidade, se nenhuma data for listada:

  • Ciclo de Vida de Requisição e Resposta: Roteamento e Middleware
    Explore o ciclo de requisição-resposta no Express, examinando como o roteamento e o middleware desempenham um papel no processamento de requisições e no envio de respostas. Este recurso oferece percepções sobre como esses componentes trabalham juntos para lidar com interações cliente-servidor de forma eficaz.
  • Arquitetura de 3 Camadas
    Aprenda sobre a arquitetura de 3 camadas, um padrão de design que separa as aplicações em três camadas interconectadas: apresentação, lógica e dados. Este recurso explica os benefícios dessa arquitetura e como ela é aplicada no desenvolvimento web moderno para criar aplicações escaláveis e fáceis de manter.
  • Introdução ao Roteamento
    Nesta Tarefa, você construirá um site de 3 páginas usando o Express, aprendendo como as URLs se mapeiam para rotas específicas em sua aplicação e como o Express serve arquivos estáticos como HTML e CSS.
  • Motores de Modelos (EJS)
    Descubra como os motores de modelos como o EJS simplificam o processo de criação de páginas web dinâmicas incorporando código JavaScript em modelos HTML. Este recurso explica os conceitos básicos do EJS, sua integração com o Express e como usá-lo para construir aplicações renderizadas no lado do servidor com modelos reutilizáveis e fáceis de manter.
  • Motor de Modelos (EJS)
    Aprenda a usar o motor de modelos EJS com o Express para gerar páginas web dinâmicas. Esta Tarefa cobre a criação de partials reutilizáveis para elementos comuns, como cabeçalhos e rodapés, e a estruturação do seu diretório de visualizações para layouts e código fácil de manter.
  • Recarregamento ao Vivo
    Este guia demonstra como configurar o recarregamento ao vivo para sua aplicação Express usando WebSockets e nodemon. O recarregamento ao vivo atualiza automaticamente seu navegador durante o desenvolvimento, otimizando seu fluxo de trabalho ao eliminar a necessidade de recarregamentos manuais de página.
