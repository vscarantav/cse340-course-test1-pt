Views Dinâmicas e Modelos com EJS

À medida que suas aplicações crescem além do conteúdo estático, você precisará renderizar páginas web com base em dados dinâmicos, estados em mudança e interações do usuário. Em vez de escrever várias cópias de arquivos HTML com pequenas diferenças, você pode usar um mecanismo de modelos para gerar páginas dinamicamente. Mecanismos de modelos tornam sua aplicação mais flexível, mantenível e escalável, separando o layout da lógica.

Neste curso, usaremos EJS (Embedded JavaScript) como nosso mecanismo de modelos. O EJS funciona perfeitamente com Node.js e Express, permitindo que você insira JavaScript diretamente em seus arquivos HTML para criar views dinâmicas e reutilizáveis.

O que é um mecanismo de modelos?

Um mecanismo de modelos permite definir um modelo (um arquivo HTML com marcadores de posição ou código incorporado) e renderizá-lo injetando dados da sua aplicação. A saída final é uma página HTML totalmente formada enviada para o navegador do usuário. Os mecanismos de modelos oferecem vários benefícios:

  • Conteúdo Dinâmico: Exibir dados que mudam em tempo de execução (informações do usuário, resultados de pesquisa, etc.).
  • Reutilização de Código: Usar modelos compartilhados (layouts, cabeçalhos, rodapés) em várias páginas.
  • Separação de Responsabilidades: Manter a lógica do lado do servidor e a apresentação do lado do cliente organizadas e modulares.

Como o EJS funciona

O EJS permite incorporar lógica semelhante ao JavaScript diretamente no seu HTML usando tags especiais. No entanto, é importante notar que o EJS não é simplesmente adicionar JavaScript ao seu HTML. Em vez disso, ele atua como uma linguagem de modelos do lado do servidor. O código JavaScript escrito dentro dos modelos EJS é executado no servidor, e o HTML simples resultante é enviado para o cliente.

Por exemplo, quando um manipulador de rota invoca res.render(), o Express processa o arquivo EJS, avalia o código incorporado e o substitui pela saída HTML correspondente. O cliente recebe apenas o HTML final renderizado, garantindo que a lógica do lado do servidor permaneça oculta.

Os modelos EJS são normalmente armazenados em um diretório chamado views. Cada arquivo de modelo usa a extensão .ejs e combina HTML padrão com tags EJS para gerar conteúdo dinâmico de forma eficiente.

Sintaxe básica do EJS

O EJS fornece várias tags especiais. Cada uma serve a um propósito diferente no controle de como os dados e a lógica são renderizados no seu HTML:

<%= %> Saída escapada

Exibe a saída do resultado de uma expressão JavaScript, com caracteres HTML escapados para segurança. Usado para exibir conteúdo gerado pelo usuário. 


        <h1>Hello, <%= user.name %>!</h1>

<%- %> Saída não escapada

Exibe a saída de HTML bruto. Use isso apenas quando tiver certeza de que o conteúdo é seguro para ser exibido. Normalmente usado para conteúdo confiável que nós (nossos desenvolvedores, nosso servidor) criamos ou geramos. 


        <div><%- user.bioHTML %></div>

Tenha cuidado com <%- %>. Se os dados vierem de usuários ou fontes não confiáveis, eles poderão conter HTML ou scripts maliciosos. Escape ou higienize esse conteúdo antes de gerá-lo na saída.

<% %> Fluxo de Controle de Lógica

Executa JavaScript sem exibir nenhuma saída. Ideal para condicionais e laços. 


        <% if (user.isLoggedIn) { %>
            <p>Welcome back!</p>
        <% } else { %>
            <p>Please log in.</p>
        <% } %>

<%# %> Comentário

Adiciona um comentário no modelo que não aparece no HTML renderizado. 


        <%# This is an internal comment for developers %>

<%% %> Tag EJS bruta

Exibe na saída um literal <% no HTML renderizado. 


        <%%= This will appear as &lt;%= in the HTML %>

Guia de referência rápida do mecanismo de modelos EJS

Este guia de referência rápida fornece uma consulta rápida para a sintaxe comum de modelos EJS e seus usos:

Sintaxe Descrição
<%= %> Exibe o valor da variável, escapado para prevenir XSS (Cross-Site Scripting).
<%- %> Exibe HTML não escapado (use com cautela para evitar XSS).
<% %> Executa código JavaScript sem gerar nenhuma saída.
<%# %> Tag de comentário, não gera nenhuma saída para o HTML renderizado.
<%% %> Exibe um literal <% no modelo renderizado.
<? ?> Sintaxe alternativa para <% %>, frequentemente usada para compatibilidade com XML.

Juntando tudo: um modelo de exemplo

A seguir está um exemplo de index.ejs arquivo usando várias tags EJS: 


        <!DOCTYPE html>
        <html>
        <head>
            <title>Welcome</title>
        </head>
        <body>
            <!-- Display the user's name, escaped for safety -->
            <h1>Hello, <%= user.name %>!</h1>

            <!-- Conditional logic to check if the user is logged in -->
            <% if (user.isLoggedIn) { %>
                <!-- Display the number of new messages -->
                <p>You have <%= user.messages.length %> new messages.</p>
            <% } else { %>
                <!-- Message prompting the user to log in -->
                <p>Please log in to see your messages.</p>
            <% } %>

            <!-- Loop through the user's messages and display each one in a list -->
            <ul>
                <% user.messages.forEach((msg) => { %>
                    <li><%= msg %></li>
                <% }); %>
            </ul>
        </body>
        </html>

Renderizando modelos EJS no Express

Assim que o EJS estiver instalado e configurado, você poderá renderizar modelos a partir dos seus manipuladores de rota usando res.render(). Aqui está um exemplo completo: 


        // Import the express module
        import express from 'express';

        // Create an instance of an Express application
        const app = express();

        // Set the view engine to EJS, so Express knows to use EJS for rendering templates
        app.set('view engine', 'ejs');

        // Define a route for the root URL ('/')
        app.get('/', (req, res) => {
            // Create a user object with some sample data
            const user = {
                name: 'Alex',
                isLoggedIn: true,
                messages: ['Welcome!', 'Do not forget to check your inbox.']
            };

            // Render the 'index' EJS template and pass the user object to it
            res.render('index', { user });
        });

        // Start the server and listen on port 3000
        app.listen(3000, () => {
            console.log('Server is running on port 3000'); // Log a message when the server starts
        });

Neste exemplo, o user objeto é passado para a index.ejs view. Dentro do modelo EJS, você pode acessar os valores usando tags EJS.

Conclusão

Motores de modelos, como o EJS, simplificam o processo de criação de conteúdo HTML dinâmico ao permitir que você injete dados e lógica diretamente em seus modelos. Eles desempenham um papel crítico na construção de aplicações web renderizadas no lado do servidor, preenchendo a lacuna entre os dados da sua aplicação e sua camada de apresentação.

Embora existam muitos motores de modelos disponíveis – como Handlebars, Mustache, e Nunjucks – cada um com suas próprias funcionalidades e sintaxe, usaremos o EJS nesta disciplina. O EJS é amplamente utilizado devido à sua simplicidade, flexibilidade e integração perfeita com o Express, tornando-o uma excelente escolha para nossos objetivos de aprendizado.
